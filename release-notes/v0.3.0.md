# Piramid v0.3.0

The first release published here, with generation built in.

- `piramid serve` runs Qwen2 and Qwen3 checkpoints on the CPU in these binaries, and on CUDA in the
  `piramid-cuda` image.
- `POST /api/generate` retrieves from a collection and generates in one request, with streaming.
  `/v1/chat/completions` and `/v1/models` follow the OpenAI format.
- Embedding providers: OpenAI-compatible servers, Ollama, and Qwen3 embedding checkpoints run
  in-process.
- Install with `curl -fsSL https://piramiddb.com/install.sh | sh`, or use the
  `ghcr.io/ashworks1706/piramid` and `piramid-cuda` images.
- The Python client is `pip install piramid`.

Docs: https://piramiddb.com/docs. `config.example.yaml` lists every setting at its default.
